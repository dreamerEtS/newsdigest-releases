# NewsDigest — інсталятори

Тут лежать лише інсталятори програми NewsDigest для Windows і файл, з якого програма дізнається про нову версію.
Коду програми тут немає, і жодних даних чи паролів теж.

Програма оновлюється сама: коли виходить нова версія, вона покаже кнопку «Оновити й перезапустити».
Завантажувати файли звідси вручну не потрібно.
